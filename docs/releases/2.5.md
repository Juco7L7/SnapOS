The Debian layer is native.

A `.deb` on SnapOS now behaves as it would on a Debian computer:

- **Install scripts run with every power**, as root, like on Debian. The limits added in 2.0 are gone.
- **Packages that bring a system service are installed** instead of refused. The program works; its service does not start inside the layer, and SnapOS says so.
- **The layer is not a sandbox.** A program in it can do what it could do on Debian.

The protection is **SnapGuard**: every `.deb` is scanned before it is installed, and a threat goes to quarantine.

Everything from 2.4.1 stays: Steam and other 32-bit programs, the update window at login, the `snapos` commands, x86_64 and ARM64 images, four desktops, SnapGuard in real time.

Flash with balenaEtcher. Checksums in the `.sha256` files.
