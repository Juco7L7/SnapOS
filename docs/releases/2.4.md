The Nix commands people need, under plain names.

SnapOS is a bridge from Debian-based distros to NixOS. This release puts the everyday Nix commands behind `snapos`:

- **Programs**: `snapos find`, `snapos add`, `snapos remove`, `snapos list`; `snapos shell` and `snapos try` use a program without installing it.
- **Changes**: `snapos diff` shows what a rebuild would change; `snapos rebuild --next-boot` applies a change at the next start only; `snapos rebuild --trace` shows the full error; `snapos log` shows the last rebuild again.
- **Going back and disk space**: `snapos rollback`, `snapos generations`, `snapos gc`.
- `nix-env -i` is stopped with an explanation and the SnapOS way.
- `snapos help` maps the apt habits to their SnapOS names, and the README shows the Nix command behind each one.

Everything from 2.3.1 stays: x86_64 and ARM64 images, package updates between releases, the unattended install, four desktops, SnapGuard in real time, the Debian layer.

Flash with balenaEtcher. Checksums in the `.sha256` files.
