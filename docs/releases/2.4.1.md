The update window shows up again, and Steam works.

**Updates are offered at login.** The check at login runs as your user, and it tried to write in a folder only root can enter, so it always failed: no window appeared, and opening SnapOS Update said the network could not be reached. Fixed:

- The login check works as a normal user.
- With no news at login, the check asks again every few hours, so a release published during the day is offered too.
- **Install now** opens the terminal of the desktop you use (Budgie, KDE Plasma, Xfce or Hyprland).
- The window also knows when an update is built and only waits for a restart, and when an update was undone.

**Coming from 2.4 or earlier:** those versions cannot show the window, so run `snapos update` once in a terminal. From 2.4.1 on, the window does it.

**Steam and other 32-bit programs.** On a PC the Debian layer now takes 32-bit (i386) packages too. When the Steam `.deb` is installed, the libraries Steam asks for (64 and 32 bit) are installed with it, so Steam opens without asking for anything.

Everything from 2.4 stays: the `snapos` commands, x86_64 and ARM64 images, package updates between releases, the unattended install, four desktops, SnapGuard in real time.
